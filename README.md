# Data Lake Miralibros - ETL
Repositorio para el proceso de extracción, transformación y carga (ETL) de los datos de Miralibros.

## Instrucciones de uso local
1. Instalar dependencias: `pip install -r requirements.txt`
2. Colocar los 4 archivos Excel/CSV originales dentro de la carpeta `/bronze` (crearla si no existe).
